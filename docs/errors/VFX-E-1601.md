# VFX-E-1601

## Title
NoRunToExplain

## Explanation
No `eventsPath` was given and no run has completed in this session. `explain_run`/`diagnose_run`
default to the most recent `run_suite` call made in the same server session when `eventsPath` is
omitted; this code fires when there is no such run to default to.

## Common causes
- `explain_run`/`diagnose_run` called with no `eventsPath`, before any `run_suite` call has completed in this session.
- A new server session or process started (for example, the MCP client reconnected), losing the previous session's last-run record.
- Intentionally trying to explain a run that happened in a different session or process, without passing its events path explicitly.

## Fixes
- Run `run_suite` first, then call `explain_run`/`diagnose_run` with no `eventsPath` to use it automatically.
- Pass `eventsPath` explicitly, pointing at a specific run's events file, to explain a run from a previous session.
- Confirm you are calling the same long-lived server instance that actually ran the suite, if last-run tracking seems to have been lost.
