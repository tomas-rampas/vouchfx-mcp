# VFX-E-1401

## Title
EngineCliUnavailable

## Explanation
The pinned `vouchfx` CLI is missing, version-mismatched, unparseable, or not launchable. Shared by all
five CLI-backed tools — `list_step_types`, `describe_step_type`, `plan_coverage`, `scaffold_suite`, and
`run_suite` — because the condition and its remediation are identical for every one of them: the
environment this server orchestrates through is not available.

## Common causes
- The `vouchfx` CLI is not installed, or not on `PATH` for the account running `vouchfx-mcp`.
- An installed CLI's version does not match this server's own `ENGINE_PIN`.
- The CLI is installed but not launchable (a corrupted install, or a missing runtime dependency such as .NET 8 when the CLI was installed without `--allow-roll-forward` on a machine that has only .NET 10), or its version output could not be parsed.
- `list_step_types` or `describe_step_type` only: the CLI could not load a configured external provider location (engine v1.2.0 and later), for example a `VOUCHFX_PROVIDERS` entry naming a directory that does not exist, so `vouchfx list --json` exited 3. The version check passes in this case, and the other CLI-backed tools report the same condition under their own codes.

## Fixes
- Install the `vouchfx` dotnet tool at the version named in this repository's `ENGINE_PIN` file. If it is already installed, uninstall it first with `dotnet tool uninstall --global vouchfx` (this is harmless when it is absent), then run `dotnet tool install --global vouchfx --version <pinned-version> --allow-roll-forward`. The pinned CLI is built for .NET 8 and has no roll-forward of its own, so the flag is required on a machine that has only .NET 10; without it the CLI exits with "You must install or update .NET to run this application", which this server reports as `VFX-E-1401` ("not found on PATH or could not start") even though the CLI is on `PATH`. `dotnet tool update` has no such option, so do not use it for this tool.
- Run `vouchfx --version` yourself to confirm it is on `PATH` and launches successfully.
- If a different CLI version is intentionally installed, this server's `ENGINE_PIN` needs advancing — a maintainer/release task, not something a single call can work around.
- Run `vouchfx list --json` in this server's environment. If it reports a provider error, correct or unset `VOUCHFX_PROVIDERS`, or repair `~/.vouchfx/providers` with `vouchfx providers uninstall` and `vouchfx providers install`; reinstalling the CLI does not help. A changed `VOUCHFX_PROVIDERS` takes effect only after this server restarts.
