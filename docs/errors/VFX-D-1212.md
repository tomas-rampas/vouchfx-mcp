# VFX-D-1212

## Title
ExternalEnvironmentSourceUnresolved

## Explanation
The suite references external environment configuration through `environment.source`.
CLI-free validation and normalisation inspect the suite document only. They do not open driver
configuration or environment files, bind logical services or dependencies, resolve secrets, or
check runtime readiness. Empty inline infrastructure lists therefore do not establish that a
target or dependency is absent.

This informational advisory reports that limitation once per suite. It does not change the schema
result or confirm that the driver is registered or its configuration is valid. Schema findings
remain separate. The current rc.6 schema rejects `environment.source`; semantic advice does not
add support to that published schema.

Inline YAML has no filesystem base. MCP never invents a current-directory base for external files.

## Common causes
- A source-backed suite analysed without resolving its external configuration.
- Inline YAML containing a relative configuration reference.

## Fixes
- Consult `get_schema` for the schema supported by the pinned engine.
- Use normal `vouchfx validate <original-suite-path>` with an engine that supports the suite's driver.
- For inline YAML, save the suite beside its configuration before engine validation.
- Preserve the original file location when planning or running; configuration paths belong to the suite.
